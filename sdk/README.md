## What is a PREZFILE?
It is a new DOOM File type I have coined.  3DO DOOM used REZFILES to store data (BurgerLib2 resource files).
So I created a 'PREZFILE' in the same way a 'PWAD' exists.  Just replacing the resource id's that the engine uses
to lookup data.
